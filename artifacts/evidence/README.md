# Program Harbor evidence

This directory contains small, reviewable local receipts for the competition entry. It deliberately excludes `.data`, credentials, generated Playwright traces, and live provider responses.

- `local-receipt.md` records the exact local checks and their scope.
- `visual-regression/` contains screenshots captured from the local production-shaped server and visually inspected before closeout.

These artifacts do not prove a public deployment, production authentication, email delivery, Airtable persistence, Accelevents writes, R2 object storage, or Cloudflare runtime behavior.
