# Program Harbor product brief

Program Harbor is an open-source program-operations desk for conferences that need to move speakers from call-for-proposals to a publishable schedule without a maze of disconnected tools. Its first release makes the operational handoffs visible: a configurable CFP routes proposals into human review, accepted speakers get a simple portal and task list, organizers see what is missing, and a canonical schedule feeds the public program.

The product is intentionally smaller than Sessionboard. It optimizes for one event team completing one full journey in a few minutes, with clear evidence when an action changes external state. The strongest differentiator is the “ready to publish” view: every accepted session exposes its onboarding gaps, schedule conflicts, communication state, and public visibility in one place.

## Success definition

An organizer can seed or configure an event, publish a conditional CFP, accept a routed proposal after a weighted review, collect speaker materials, schedule the session without hiding conflicts, generate an invite, and expose the approved session publicly. A judge can repeat that journey after a reset without reading a manual or waiting for a real email.
